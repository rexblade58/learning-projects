# Contributing

Thanks for helping improve the learning exercises!

## Adding an Exercise

1. Fork the repository
2. Create a folder under the relevant topic: `html-css/`, `javascript/`, `react/`, `node-api/`, or `python/`
3. Include a working starter and a solution
4. Update the README table
5. Submit a pull request

## Exercise Guidelines

- Keep each exercise self-contained in its own folder
- Include clear instructions as comments or a short `README.md`
- Solutions must work when opened directly in a browser (no build step for HTML/CSS/JS)
- Node exercises should include a `package.json`

## Code of Conduct

Be respectful, constructive, and inclusive.
